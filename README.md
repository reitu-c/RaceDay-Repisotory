# RaceDay Event Management System

## Project Description

RaceDay is a full-stack event management system designed for South African road running, walking, and cycling events.

The system provides a central platform for organisers and participants to manage events, event categories, enrolments, results, routes, and weather information.

Part 1 focuses on the planning and database foundation of the system. This includes the Entity Relationship Diagram (ERD), API Endpoint Plan, SQL Server database design, repository structure, and continuous integration using GitHub Actions.

## User Roles

### Organiser

The Organiser is responsible for managing race events on the RaceDay platform. Organisers can create and update events, manage event categories, view participant enrolments, add race results, and manage route information.

### Participant

The Participant uses RaceDay to browse available events, view event categories, enrol in events, view their enrolments, and access their race results.
